# CSS Position Properties

This is a fun project for a clear understanding of CSS position properties and z-index

## 1. `static`
- Default position; elements are placed in the normal document flow without special positioning.

## 2. `relative`
- Positions the element relative to its normal position, allowing offsets using `top`, `right`, `bottom`, `left`.

## 3. `absolute`
- Positions the element relative to the nearest positioned ancestor (non-static), removing it from the normal flow.

## 4. `fixed`
- Positions the element relative to the viewport, staying fixed even when the page is scrolled.

## 5. `sticky`
- Behaves like `relative` until a given scroll threshold is met, then sticks like `fixed`.

## 6. `z-index`
- Controls the stacking order of elements on the z-axis (which element appears in front or behind).
